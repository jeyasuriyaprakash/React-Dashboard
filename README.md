# React Dashboard

A professional portfolio-level dashboard built with **React JS, TypeScript, Bootstrap and Bootstrap Icons**.

## UI Highlights

- Modern dark sidebar navigation
- Responsive mobile navigation drawer
- Sticky top header with notifications and profile
- KPI/statistic cards with trends
- Project activity chart built with CSS
- Recent activity timeline
- Featured projects with progress indicators
- Developer tech-stack section
- Responsive desktop, tablet and mobile layouts
- Portfolio-focused visual hierarchy and spacing

## Tech Stack

- React JS
- TypeScript
- Bootstrap
- Bootstrap Icons
- Vite
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
